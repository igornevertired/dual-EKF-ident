# Полная таблица входных параметров симуляции

Документ описывает **все входные параметры** рабочей цепочки  
`run_full_sim.py` → `simulation/bins_gnss_simulation.py`.

Численные значения начального состояния получены из `initsim()` при текущей версии кода (балансировка для `H=500 м`, `V=80 м/с`).

---

## 1. Параметры запуска симуляции

| Параметр | Значение | Единица | Описание | Файл |
|----------|----------|---------|----------|------|
| `tmodel` | **30.0** | с | Длительность прогона в `run_full_sim.py`. После этого времени цикл останавливается. | `run_full_sim.py` |
| `dt` | **0.001** | с | Шаг интегрирования FX1 (RK4) и БИНС. На каждом шаге: FX1 → ошибки ДУС/ДЛУ → `bins_step`. | `bins_gnss_simulation.py` |
| `dt_gnss` | **0.1** | с | Период выдачи измерений ГНСС и шага ОФК. Каждые 100 шагов `dt` вызываются `gnss()` и `ofk_step()`. | `bins_gnss_simulation.py` |
| Период автопилота | **0.01** | с | Как часто пересчитывается управление `u` по программе полёта (тяга, рули). | `bins_gnss_simulation.py` |
| `TMODEL` | **1000** | с | Внутренний горизонт в `initsim()` (из MATLAB). В текущем `run_full_sim` **не используется** — там свой `tmodel=30`. | `initsim.py` |
| `TGLIDE` | **10800** | с | Время включения режима планирования в FX1 (3 ч). При `time > TGLIDE` в уравнения добавляется слагаемое `dd` по углу траектории (посадочная логика). При `tmodel=30` с **не срабатывает**. | `initsim.py`, `fx1.py` |
| Seed INS (bias) | **42** | — | Зерно ГПСЧ для **постоянных** смещений нуля ДУС и ДЛУ. Один раз при старте генерируются `dw_bias` (3 оси гироскопа) и `da_bias` (3 оси акселерометра). Одинаковый seed → одинаковые bias при повторном запуске. | `imu_error_generator.py` |
| Seed INS (шум) | **43** | — | Зерно для **белого шума** на каждом шаге `dt`. Фактически `seed+1` от bias (= 43). Независимый поток от bias, чтобы шум и смещение не коррелировали. | `imu_error_generator.py` |
| Seed GNSS | **123** | — | Зерно ГПСЧ для случайных ошибок измерений ГНСС (`φ, λ, h, Vn, Ve, Vh`). Отдельно от INS — шум навигации и инерции воспроизводятся независимо. | `bins_gnss_simulation.py` |

**Seed** — начальное число генератора псевдослучайных чисел (`numpy.random.default_rng`). Фиксирует последовательность шума: при тех же seed результаты повторяются; при смене seed — другая реализация тех же СКО.

## 4. Аэродинамические коэффициенты (`PAR[6..46]`)

Коэффициенты входят в полиномиальные зависимости сил и моментов в `fx1.py`.  
Источник значений: `simulation/initla.py`. Формулы — `docs/MATHEMATICAL_MODEL_AIRCRAFT.md`, §4.

### Входные переменные в формулах

| Переменная | Обозначение | Единица | Смысл |
|------------|-------------|---------|-------|
| `alp` | α_g | ° | Угол атаки: `α·180/π + alpkr`, где `α = −arctan(Vy/Vx)` |
| `be` | β_g | ° | Угол скольжения: `β·180/π` |
| `delta_v` | δ_V | ° | Отклонение **руля высоты** (из состояния `x[16]`) |
| `delta_n` | δ_N | ° | Отклонение **руля направления** (`x[17]`) |
| `delta_e` | δ_E | ° | Отклонение **элеронов** (`x[18]`) |
| `fist` | φ_ist | ° | Постоянный угол установки хвостового оперения, `PAR[51]=−3.9026` |
| `omgx, omgy, omgz` | Ω_x, Ω_y, Ω_z | — | Безразмерные угловые скорости в скоростной СК: `ω·l/(2V)` или `ω·ba/V` |
| `dalp`, `dbe` | dα/dt, dβ/dt | рад/с, рад/с | Производные аэродинамических углов по времени |

Скоростной напор: `qdyn = ½·ρ·V²·S·‖g_Tg‖`. Силы: `Fx=Cx·qdyn`, `Fy=Cy·qdyn`, `Fz=Cz·qdyn`.  
Моменты: `Mx=mx·qdyn·l`, `My=my·qdyn·l`, `Mz=mz·qdyn·ba`.

### 4.1. Коэффициент подъёмной силы Cy (продольная сила в скоростной СК)

\[
C_y = C_{y0} + C_y^{\alpha}\,\alpha_g + C_y^{\delta_V}\,\delta_V + C_y^{\varphi_i}\,\varphi_{ist}
\]

### Параметры шума GNSS

| Канал | `σ` | Единица | Модель |
|-------|-----|---------|--------|
| `φ` | **5×10⁻⁶** | рад | `N(0, σ²)` |
| `λ` | **5×10⁻⁶** | рад | `N(0, σ²)` |

| `Vn` | **0.2** | м/с | `N(0, σ²)` |
| `Ve` | **0.2** | м/с | `N(0, σ²)` |
| `Vh` | **0.2** | м/с | `N(0, σ²)` |

Источник: `sensors/core.py` → `gnss()`.

Порядок `np_gnss`: `[φ, λ, h, Vn, Ve, Vh]`.

## 13. Параметры EKF (ОФК)

### Начальное состояние

| Параметр | Значение |
|----------|----------|
| `x_ofk` | `zeros(15)` |
| `P0` (база) | `diag(1000×4, 0.01×6, 0.0001×5)` |
| `P0[13]` (δVh) | **0.04** |
| `P0[14]` (δh) | **1.0** |

### Процессный шум `Q`

`Wq = [20e-10, 20e-10, 20e-10, 25e-7, 25e-7, 25e-7]`  
`Q = diag((Wq²) / dt_gnss)`

### Шум измерений `R`

`R = diag(σ²_GNSS)` с порядком каналов инновации:  
`[φ, λ, Vn, Ve, Vh, h]`

Минимальные пороги дисперсии (`variance floor`):  
`[1e-14, 1e-14, 1e-4, 1e-4, 1e-4, 1e-2]`

### Инновация

`z = np_bins − np_gnss` (порядок как в `build_innovation`).
