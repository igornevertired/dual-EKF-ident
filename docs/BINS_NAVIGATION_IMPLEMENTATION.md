# Где и как реализован БИНС (ИНС) в проекте

Документ описывает **механизацию одного канала навигации** в пакете `src/model_python_port`: какие файлы участвуют, как формируются измерения ДУС/ДЛУ, как шаг состояния, связь с эталоном полёта.

---

## 1. Карта модулей

| Компонент | Файл | Назначение |
|-----------|------|-------------|
| **Шаг интеграции навигации** | [`bins_common.py`](../src/model_python_port/bins_common.py) | функция `bins_step` (алиас `bins`): скорость, φ/λ/h в `np`, кватернион, `Cbn` |
| **Начало ориентации** | [`initivk.py`](../src/model_python_port/initivk.py) | `initivk(x0)` — начальные `CBN0`, кватернион `Qu` из углов `FX1` |
| **Приборные ошибки ДУС/ДЛУ** | [`imu_error_generator.py`](../src/model_python_port/imu_error_generator.py) | класс `InsErrorGen`: байасы + белый шум на выходах гироскопа и акселерометра |
| **Модель Земли для БИНС** | [`earthmodel.py`](../src/model_python_port/earthmodel.py) | радиусы кривизны, гравитация под шаг механизации |
| **Сборка симулятора** | [`bins_gnss_simulation.py`](../src/model_python_port/bins_gnss_simulation.py) | вызов `bins_step` на каждом шаге `dt` после `fx1` / RK4 |
| **Выходы траектории «истины» для датчиков** | [`fx1.py`](../src/model_python_port/fx1.py) | истинное `ω` и ускорение в связке, подаваемые в генератор ошибок |

Полное описание сценария «ЛА + БИНС + ГНСС + ОФК» — в [SIMULATION_BINS_GNSS.md](SIMULATION_BINS_GNSS.md). Отдельно про приёмник — [GNSS_MODEL_IMPLEMENTATION.md](GNSS_MODEL_IMPLEMENTATION.md).

## 2. Вектор навигационного решения `np_bins`

В симуляторе используется **шестёрка** совместно с блоком фильтра:

```text
np_bins = [ Vn ,  V_vertical_channel ,  Ve ,  h ,  φ ,  λ ]
```

- **φ, λ, h** — геодезические широта/долгота (рад/рад/м).
- **Vn, Ve** — северная и восточная составляющие скорости в навигационной СК модели.

Второй компонент задаётся **как производная высоты** по эталону полёта: на каждом шаге механизации в `bins_gnss_simulation` подставляется `dh_et = v_nav[1]` (вертикальная скорость из перехода `c_gb` из истины `FX1`), а высота решения **`np_bins[3]` принудительно равна** `x[10]` («истина» высоты). То есть вертикальный канал **жёстко привязан к эталонной траектории**, а инерциальное накопление ошибок по высоте в чистом виде не наблюдается — это упрощение учебной постановки.

## 3. Вычисление шага БИНС: `bins_step`

Реализовано в [`bins_common.bins_step`](../src/model_python_port/bins_common.py).

На вход поступает:

- **a** — вектор ускорений в связанной СК (уже после `InsErrorGen`);
- **w** — вектор угловых скоростей в связанной СК (тоже зашумлённый);
- **np_prev** — предыдущее навигационное решение;
- **cbn_prev**, **q_prev** — матрица `C_bn` навигация→связанная и кватернион;
- **dt** — шаг интегрирования;
- **h_et**, **dh_et** — эталонные высота и её производная (подстановка после интегратора).

На выход: обновлённые **q_new**, **cbn_new**, **np_new**.

### 3.1. Производные скоростей и координат

- Ускорение в связке переводится в навигационную систему: `a_nav = Cbn_prev @ a`.
- Учитываются **вращение Земли** (`Üe`), **центробежное** и **кориолисово** члены через вектора `wei_n`, `ap_n`, `ak_n`.
- Учитывается **относительное вращение** навигационной СК через `wge_n`, член `at_n`.
- Прибавляется **гравитация** из `earthmodel`.

Сумма задаёт производные компонентов скорости; интегрирование даёт продвижение **`np_bins[0]`**, **`[1]`**, **`[2]`**. Производные **φ** и **λ** связывают скорости с радиусами кривизны модели земного эллипсоида (см. формирование массива `dnp` в коде).

### 3.2. Принудительная подстановка вертикали

После интегрирования по скорости:

- `np_new[3] = h_et`;
- `np_new[1] = dh_et`.

То есть высота решения БИНС и выбранный вертикальный канал решения связаны с **эталоном полёта** из симулятора, а не только с инегрируемой инерцией.

### 3.3. Ориентация (кватернион → `Cbn`)

По измеренной **w** формируется угловая скорость в связке относительно навигационной (**wbnb**) с вычитанием переноса навигационной системы (**wni_b** через `cbn_prev.T`). Кватернионные производные задают переход **`q`**; из **`q_new`** строится **`cbn_new`** (`_quat_to_cbn`).

## 4. Инициализация БИНС в `run_simulation`

В [`bins_gnss_simulation.run_simulation`](../src/model_python_port/bins_gnss_simulation.py):

1. Из **initsim** берётся `x0`; **initivk** даёт **`Qu`**, **`CBN0`**.
2. По **c_gb(x)** формируется проекция скорости истины на навигационные оси; **`np_bins`** и собирается в шестёрку (начальное выравнивание по скоростям от первого наблюдения ГНСС — см. тот же модуль при `gnss_idx == 0`).

## 5. Моделирование ошибок ДУС и ДЛУ

Реализация: [`imu_error_generator.InsErrorGen`](../src/model_python_port/imu_error_generator.py).

| Величина | Модель | Значения по умолчанию |
|----------|--------|-------------------------|
| **Байас гироскопа**, по каждой оси | один раз при создании: `Gaussian(0, 0.5 °/ч)` → перевод в рад/с | среднеквадратичное 0.5 °/ч |
| **Байас акселерометра**, по каждой оси | один раз при создании: `Gaussian(0, 5×10⁻⁴)` | м/с² |
| **Белый шум ω**, каждый такт | независимые выборки | СКО `10⁻⁵` (на один вызов) |
| **Белый шум a**, каждый такт | независимые выборки | СКО `5×10⁻⁵` м/с² |

Фактически: **ω_meas = ω_ист + ω_bias + белый**, **a_meas = a_ист + a_bias + белый**.

Это эвристический порт концепции **GENERATOR_SV.m**.
