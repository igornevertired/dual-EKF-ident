# Начальные значения и моделируемые ошибки симуляции

Документ описывает параметры, с которыми запускается цепочка **`run_full_sim.py` → `bins_gnss_simulation.run_simulation`**.  
Численные значения начального состояния получены из `initsim()` (балансировка ЛА) при текущей версии кода.

## 6. Ошибки инерциальных датчиков (ДУС / ДЛУ)

Класс: `InsErrorGen` (`imu_error_generator.py`), seed **42** (bias) и **43** (шум).  
Добавляются **каждый шаг `dt`** после FX1, до `bins_step`.

### 6.1. ДУС (гироскоп) — искажает `wbi_b` → `w_m`

| Компонента | Тип ошибки | Параметр | Значение | Единица |
|------------|------------|----------|----------|---------|
| ωx, ωy, ωz | **bias** (постоянный на прогон) | σ | **0.5** | °/ч |
| | | распределение | N(0, σ²), независимо по осям | |
| | | пример (seed=42), °/ч | [0.15, −0.52, 0.38] | °/ч |
| ωx, ωy, ωz | **белый шум** (каждый шаг) | σ | **1×10⁻⁵** | рад/с |

Модель: `w_m = w_true + bias_ω + N(0, σ_noise²)`.

### 6.2. ДЛУ (акселерометр) — искажает `af_bi_b` → `a_m`

| Компонента | Тип ошибки | Параметр | Значение | Единица |
|------------|------------|----------|----------|---------|
| ax, ay, az | **bias** (постоянный на прогон) | σ | **5×10⁻⁴** | м/с² |
| | | распределение | N(0, σ²) | |
| | | пример (seed=42) | ≈ [4.8, −9.9, −6.6]×10⁻⁵ | g |
| ax, ay, az | **белый шум** (каждый шаг) | σ | **5×10⁻⁵** | м/с² |

Модель: `a_m = a_true + bias_a + N(0, σ_noise²)`.

## 7. Ошибки измерений ГНСС

Функция: `core.gnss()`, seed **123**.  
Вызывается **каждые `dt_gnss = 0.1` с** к истинным координатам и скоростям FX1.

| Канал | Истинное значение | СКО ошибки σ | Единица | Модель |
|-------|-------------------|--------------|---------|--------|
| φ (`Fi`) | `x[12]` | **5×10⁻⁶** | рад | `φ_gnss = φ + N(0, σ²)` |
| λ (`Lm`) | `x[13]` | **5×10⁻⁶** | рад | `λ_gnss = λ + N(0, σ²)` |
| h (`H`) | `x[10]` | **1.0** | м | `h_gnss = h + N(0, σ²)` |
| Vn | `v_nav[0]` | **0.2** | м/с | `Vn_gnss = Vn + N(0, σ²)` |
| Ve | `v_nav[2]` | **0.2** | м/с | `Ve_gnss = Ve + N(0, σ²)` |
| Vh | `v_nav[1]` | **0.2** | м/с | `Vh_gnss = Vh + N(0, σ²)` |

Ковариация измерений в ОФК: **`R = diag(σ²)`** с перестановкой каналов под матрицу `H` (`loosely_coupled_ofk.build_measurement_covariance`).

## 8. Оптимальный фильтр Калмана (ОФК)

### 8.1. Вектор ошибок `x_ofk` (15 состояний)

Начальное значение: **`x_ofk = 0`** (error-state reset после каждой коррекции).

| Индекс | Состояние | Начальная ошибка | Модель в фильтре |
|--------|-----------|------------------|------------------|
| 0–2 | ошибки угла (платформа) | 0 | динамика из `F` |
| 3 | δVn | 0 | |
| 4 | δVe | 0 | |
| 5 | δφ | 0 | |
| 6 | δλ | 0 | |
| 7–9 | bias ДУС (оценка) | 0 | случайное блуждание, `Q` |
| 10–12 | bias ДЛУ (оценка) | 0 | случайное блуждание, `Q` |
| 13 | δVh | 0 | затухание τ=1 с |
| 14 | δh | 0 | затухание τ=1 с |

### 8.2. Начальная ковариация `P₀` (диагональ)

Задаётся в `bins_gnss_simulation.py` (упрощённо, не из `sensor_error_params.py`):

| Индексы состояний | P₀ (диагональ) | Примечание |
|-------------------|----------------|------------|
| 0–3 | **1000** | углы / скорости (4 шт.) |
| 4–9 | **0.01** | координаты и bias (6 шт.) |
| 10–14 | **0.0001** | bias ДЛУ + Vh, H (5 шт.) |

### 8.3. Шум процесса `Q` (матрица 6×6)

Из `bins_ofk_2ch.build_bins_ofk_2ch_matrices`, на шаг `dt_gnss`:

| Канал шума | √Q (в коде `wq`) | Единица (условно) | В `Q` |
|------------|------------------|-------------------|-------|
| ДУС x, y, z | **20×10⁻¹⁰** | — | `(wq²) / dt_gnss` |
| ДЛУ x, y, z | **25×10⁻⁷** | — | `(wq²) / dt_gnss` |

### 8.4. Измерения ОФК `z` (6 каналов)

`z = np_bins − np_gnss` (разность БИНС и ГНСС):

| Компонента z | Смысл |
|--------------|-------|
| z₀ | δφ |
| z₁ | δλ |
| z₂ | δVn |
| z₃ | δVe |
| z₄ | δVh |
| z₅ | δh |

## 9. Навигационные каналы в логе (что сравнивается с истиной)

Лог пишется на тактах ГНСС (`dt_gnss`). Для каждого канала:

| Канал | Истина (`true_*`) | БИНС до ОФК (`bins_*`) | После ОФК (`ofk_*`) | ГНСС (`gnss_*`) |
|-------|-------------------|----------------------|---------------------|-----------------|
| φ | `x[12]` | `np_bins[4]` до коррекции | `np_bins[4]` после | `np_gnss[0]` + шум |
| λ | `x[13]` | `np_bins[5]` | `np_bins[5]` | `np_gnss[1]` + шум |
| h | `x[10]` | `np_bins[3]` | `np_bins[3]` | `np_gnss[2]` + шум |
| Vn | `v_nav[0]` | `np_bins[0]` | `np_bins[0]` | `np_gnss[3]` + шум |
| Ve | `v_nav[2]` | `np_bins[2]` | `np_bins[2]` | `np_gnss[4]` + шум |
| Vh | `v_nav[1]` | `np_bins[1]` | `np_bins[1]` | `np_gnss[5]` + шум |

Ошибки в графиках ±3σ: `err_ofk_* = ofk_* − true_*`, полоса `±3√Pᵢᵢ`.

## 13. Сводная схема: где появляется ошибка

```
FX1 (истина, без ошибок)
    ↓ wbi_b, af_bi_b
InsErrorGen  →  bias + белый шум ДУС/ДЛУ
    ↓ w_m, a_m
bins_step    →  дрейф Vn, Ve, φ, λ (h, Vh из эталона)
    ↓ каждые 0.1 с
gnss()       →  гауссов шум 6 каналов PVT
    ↓
ОФК          →  оценка и коррекция np_bins
```
