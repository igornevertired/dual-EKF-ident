# Бортовая идентификация модели продольного движения ЛА: БИНС + СНС + ОФК-1 + ОФК-2

Python-порт учебной MATLAB-модели пассажирского самолёта и двухэтапный алгоритм:

1. **ОФК-1** — фильтр Калмана по ошибкам БИНС (слабосвязанная схема с СНС, 15 состояний).
   Оценки в счисление БИНС не вводятся, ими корректируются только выходы для потребителей.
2. **ОФК-2** — расширенный фильтр Калмана, который по выходам ОФК-1 оценивает коэффициенты
   линеаризованной модели продольного движения (система (15), 4 уравнения).

## Запуск

```bash
poetry install
poetry run python run_full_sim.py
```

Сценарий (длительность, шаги, манёвр) задаётся константами в начале `run_full_sim.py`.
Графики сохраняются в `src/plots/`.

## Как задать манёвр

```python
from src.model_python_port.dynamics.maneuvers import Maneuver
from src.model_python_port.simulation.bins_gnss_simulation import run_simulation

data = run_simulation(tmodel=240, dt_ofk2=0.2,
                      maneuver=Maneuver("doublet", amp_deg=5, pulse_s=2.5, hold_throttle=True))
```

| `kind` | Сигнал на руль высоты | Параметры |
|---|---|---|
| `doublet` | дублет ±A | `amp_deg`, `pulse_s`, `t0`, `extra_t0` (повторы) |
| `3211` | 3-2-1-1 | `amp_deg`, `unit_s` |
| `pulse` | одиночный импульс | `amp_deg`, `pulse_s` |
| `multisine` | сумма гармоник k/T до `f_max_hz`, фазы Шредера | `amp_deg` (пик), `duration_s`, `f_max_hz` |
| `chirp` | развёртка 0,05 Гц → `f_max_hz` | `amp_deg`, `duration_s` |
| `none` | без манёвра рулём | — |

Дополнительно: `throttle_amp`, `throttle_t0`, `throttle_pulse_s` — дублет РУД;
`hold_throttle=True` — автомат тяги отключён и РУД держится на балансировке на время манёвра
(+`hold_after_s`). При фиксированном РУД коэффициент `Xδt` ненаблюдаем и автоматически
исключается из оцениваемых.

На интервале манёвра канал руля высоты автопилота отключён (не гасит возбуждение).

## Исходные данные

- Режим: горизонтальный полёт, H₀ = 500 м, V₀ = 80 м/с; балансировка δT = 0,640, α = 0,2112 рад, δв = −7,116°.
- ДУС: смещение 0,003 °/ч (СКО), шум 1·10⁻⁵ рад/с на шаге; ДЛУ: смещение 25 мкg, шум 5·10⁻⁵ м/с².
- СНС: СКО 6,6 м по координатам и высоте, 0,05 м/с по скорости.
- ОФК-1: P₀ по таблицам точности (углы 1·10⁻⁵…2·10⁻⁵ рад, скорость 0,02 м/с, координаты ≈1 м, смещения датчиков).

## ОФК-2

Модель (отклонения от балансировки, θ — угол наклона траектории):

```
ΔV̇  = Xα Δα + Xδe Δδe + Xv ΔV + Xθ Δθ + Xδt ΔδT
Δα̇  = Lα Δα + Lq Δωz + Lδe Δδe + Lv ΔV + Lθ Δθ        (Lq ≡ 1)
Δθ̇  = Θα Δα + Θδe Δδe + Θv ΔV + Θθ Δθ
Δω̇z = Mα Δα + Mq Δωz + Mδe Δδe + Mv ΔV + Mθ Δθ + Mδė Δδ̇e
```

- Вектор состояния: 20 коэффициентов + [Δα, Δωz, ΔV, Δθ].
- Оцениваются (по умолчанию): Lα, Lδe, Mα, Mq, Mδe, Xα, Xδe, Θα, Xδt; остальные — на балансировке.
- Измерение: Z = [Δα, Δωz, ΔV, Δθ]; α, V — по скорости и Cbn после ОФК-1, θ: tg θ = Vh/√(Vn² + Ve²).
- Прогноз — РК4 на 4 подшагах с интерполяцией δe, δT; матрица перехода — центральными разностями;
  ковариация — в форме Джозефа.
- Эталон: численная линеаризация полной модели FX1 в точке балансировки (`ofk2_theory.py`)
  и в текущей точке траектории (для сравнения во времени).

## Выходные данные

`run_simulation` возвращает словарь массивов: истина (`true_*`), БИНС (`bins_*`, `err_bins_*`),
ОФК-1 (`ofk_*`, `ofk_std_*`, `err_ofk_*`), СНС (`gnss_*`), ОФК-2 (`ofk2_params`, `ofk2_std`,
`ofk2_theory`, `ofk2_innov_prior`, `ofk2_innov_std`), эталон (`sp_theory`, `sp_theory_vec`),
а также `maneuver` и `estimated_params`.
